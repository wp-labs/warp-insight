crates/gateway-web · 改造对照

网关控制台：交互与视觉改造

左列为改造前、右列为改造后，均取自同一台运行中的网关（localhost:3000，2 台真实 Agent） 与同一视口，截图由无头浏览器实时渲染。

风格是否适合？—— 方向对，实现不够

  • 深色 + 等宽数字 + 语义色 适合这个定位，不用换。网关是常驻盯屏的机队控制台， 深色降疲劳、等宽数字防抖，和 Grafana / VictoriaMetrics / Datadog 同一套语言。
  • 真正的问题不在配色，而在 信息架构：定位是"多主机 agentd 采集指标与日志汇聚到网关"， 但页面主体是 Agent 管理台 —— 主机列表只有卡片、不能排序筛选，日志侧完全缺位。
  • 其次是 一致性与可用性缺陷：暗色主题里漏出白底输入框、初始化页把模型术语直接渲染给用户、 趋势图没有 Y 轴与悬停取值、两个指标口径写错。

逐页对照

01 Agent 总览 /

KPI 磁贴原本"数字大字 + 一行小字"，缺判断依据；指标口径写错（"上报延迟 5456 分钟"） 且异常数恒为 0 却挂红色条 —— 容易被误读成告警。

改造前
改造后
KPI 磁贴统一为「标签 / 数值 / 判断依据」三层，左侧色条表达状态
"最近上报间隔 5456 分钟" → 相对时间，且按源码真实语义改名为"最久未重新上线"
异常数为 0 不再着绿，改为中性色（后端异常规则尚未启用）
在线率一并展示，1/2 在线直接可读
Agent 卡片上的"在线"改为按 5 分钟窗口真实判定，掉线显示离线时长
迷你趋势线加面积填充并降采样，100 个点不再糊成色块
02 主机指标（机队视图） /hosts

这是与"多主机"定位最不匹配的一页：卡片网格无法排序、无法筛选、无法搜索， 且内存总量缺失时会渲染出 / …。10 台主机就已经不可用了。

改造前
改造后
卡片网格 → 机队表格，默认按严重度排序，需处理的永远在最上面
表头可点排序（主机 / 状态 / CPU / 内存 / 磁盘），支持升降序
搜索主机 ID + 状态筛选片（含各档数量）
内存、磁盘加进度条与阈值着色（≥90% 危急，≥75% 偏高）
修复内存总量缺失时渲染成 "/ …" 的缺陷
加载态从"加载中…"改为骨架屏，空态给出下一步动作
03 主机详情 /agents/:agentId/metrics

改造前的趋势图被纵向拉伸到失真、没有 Y 轴、没有刻度、没有悬停取值， 图上唯一能读到的数字是图例里最后一个点。

改造前
改造后
重写 TrendChart：Y 轴刻度 + 虚网格 + 面积渐变，去掉纵向拉伸
悬停十字准线 + 数值气泡，可读任意时刻的三条线取值
数据断档处断线，不再把缺失画成一条骗人的斜坡
刻度文案自动去重（磁盘 98.6%→99.0% 这种窄量程不再出现重复标签）
KPI 磁贴改为「大数值 + 进度条 + 分级文案」，磁盘 98.8% 直接标危急
补充 Agent 版本 / 实例 / 在线时长 / Admin 延迟等身份信息
04 控制中心 /control

暗色主题里两个输入框是白底、占位文字几乎看不见；目标主机靠手输、 默认值还是假的 agent-prod-001；而且暂停这种不可逆操作点一下就直接派发。

改造前
改造后
全局表单基线 + 组件样式：暗色主题下不再漏出白底输入框
目标 Agent 改为可补全下拉，数据来自真实 Agent 列表，同时允许手输未上报主机
去掉假默认值（agent-prod-001 / v0.3.2），改为必填 + 示例占位
暂停与升级走两段式确认，改动目标即作废待确认态
回执卡显示受理/拒绝状态徽标，派发失败显示错误原因
"用例信息" 等模型术语改为「暂停采集 / 远程升级」+ 说明文案
05 安装 Agent /install

命令块用红色标关键字 —— 在运维界面里红色代表故障，一段正常命令看起来像报错； 页头也没有告诉用户"装完之后去哪儿确认"。

改造前
改造后
语法着色去掉红色系：关键字改紫、管道与重定向单独着色
代码块改为独立深色代码面 + 边框，行高放宽到 1.75
页头补三步流程，明确"装完回主机指标确认上报"
标题与侧边栏统一为「安装 Agent」，并区分按架构选择命令
06 初始化 Gateway /init

这是最明显的一页：模型内部术语被直接渲染出来 —— GATEWAY / INITIALIZEGATEWAYVIAURL、USECASE、 InitializeGatewayViaUrl → GatewayInitialConfig、 "触发 InitializeGatewayViaUrl"。

改造前
改造后
删除全部模型术语：面包屑、USECASE 标签、类型流转条、触发器提示
改为面向操作者的三步说明 + "一次性操作"提示
按钮风格与全局统一（原为浅底蓝字，与站内主按钮不一致）
提交前提示"材料只能消费一次"，降低误操作概率
